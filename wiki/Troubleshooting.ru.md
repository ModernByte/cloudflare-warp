# Устранение неполадок

[English](Troubleshooting.md) · [Русский](Troubleshooting.ru.md)

Большинство проблем видно прямо в подсказке значка и в заголовке панели: короткая
причина и предлагаемое действие. Ничего из перечисленного ниже не требует правок
плагина — каждый фикс это либо кнопка в панели, либо одна команда в терминале.

## Симптом → решение

| Симптом | Причина | Решение |
|---|---|---|
| Значок показывает «Не установлен» | `warp-cli` не найден в PATH | Установите пакет Cloudflare WARP, затем нажмите **Обновить** в панели. |
| «Демон недоступен» / предупреждение о сервисе | Фоновый сервис `warp-svc` не запущен | Запустите его в терминале: `sudo systemctl start warp-svc`, затем **Обновить**. Сам плагин sudo не вызывает. |
| «Не зарегистрирован» | На этом устройстве ещё нет аккаунта WARP | Нажмите **Зарегистрировать** в панели или один раз выполните `warp-cli registration new`. |
| Запрос принятия условий использования | Свежая установка, ToS ещё не приняты | Выполните один раз в терминале: `warp-cli --accept-tos status`. |
| Красная ошибка после действия | Команда завершилась с ошибкой или была прервана по таймауту | Подсказка и панель показывают причину (например, `timeout`, `command-failed`). Нажмите **Обновить**; если не помогает — проверьте `warp-cli status` в терминале. |
| Долгое «Подключение…» | WARP повторяет попытки в фоне, либо туннель действительно недоступен | Дождитесь завершения перехода; затем переключите выключатель или выполните `warp-cli disconnect` и `warp-cli connect`. |
| Выбор режима неактивен | В клиенте включена политика *Switch Locked* | Ничего не сломано — режим заблокирован администратором аккаунта. Если аккаунт ваш, отключите Switch Lock в настройках WARP. |
| Публичный IP / локация не появляются | Проверка trace отключена или заблокирована | Включите **Автопроверку** в настройках плагина; убедитесь, что `https://www.cloudflare.com/cdn-cgi/trace` доступен из вашей сети. |
| Статус устарел после изменения из терминала | Плагин опрашивает состояние по таймеру | Подождите один цикл опроса (по умолчанию 3 с) или нажмите **Обновить**. |

## Коды ошибок

При сбое панель показывает код. Значения:

| Код | Значение | Что делать |
|---|---|---|
| `cli-missing` | `warp-cli` не найден | Установите пакет клиента WARP. |
| `daemon-down` | `warp-svc` не отвечает | Запустите сервис (`sudo systemctl start warp-svc`). |
| `unregistered` | На устройстве нет аккаунта | Нажмите **Зарегистрировать**. |
| `timeout` | Команда CLI выполнялась слишком долго | Повторите через **Обновить**; проверьте клиент в терминале. |
| `command-failed` | CLI вернул ошибку | Прочитайте сообщение в подсказке; обычно помогает **Обновить**. |
| `decode-failed` | Непривычный формат вывода CLI | Обновите клиент WARP и плагин, затем **Обновить**. |

## Только один WARP-плагин

Плагин обменивается состоянием через глобальные каналы Noctalia. Если у вас
установлен ещё какой-нибудь плагин Cloudflare WARP, держите включённым ровно
один — два опрашивающих экземпляра будут конфликтовать из-за одного `warp-cli`.

## Если ничего не помогло

1. Выполните в терминале и сравните с панелью:
   ```sh
   warp-cli --version
   warp-cli status
   warp-cli settings list
   ```
2. Посмотрите лог Noctalia на ошибки плагина:
   ```sh
   grep cloudflare-warp ~/.cache/noctalia/noctalia.log | tail -20
   ```
3. Перезагрузите плагин (Настройки → Плагины → выключить, включить) — при
   перезагрузке заново опрачивается CLI и перестраивается панель.
4. Если поведение отличается от этой документации, создайте issue:
   https://github.com/ModernByte/cloudflare-warp/issues.
