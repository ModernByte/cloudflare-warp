# Cloudflare WARP для Noctalia

[English](Home.md) · [Русский](Home.ru.md)

Плагин для управления официальным клиентом **Cloudflare WARP** прямо из оболочки
Noctalia: значок состояния в панели, плитка переключения в Control Center и
полноценная панель управления. Для повседневных действий терминал не нужен.

## Кратко

- **Значок в панели** — левый клик открывает панель, правый переключает WARP, наведение даёт подробности.
- **Плитка Control Center** — подключение/отключение одним кликом.
- **Панель** — кнопка питания, режим и протокол, DNS-фильтрация, аккаунт, карточка публичного IP.
- Интерфейс на **английском и русском**, по языку Noctalia.
- **Безопасен по конструкции** — запускает `warp-cli` только от вашего пользователя,
  никогда не использует `sudo`, а единственный необязательный сетевой запрос можно
  выключить в настройках.

Требуется клиент Cloudflare WARP (`warp-cli` / `warp-svc`) и Noctalia с уровнем
plugin API 24 или новее. Лицензия MIT, Modern Byte.
