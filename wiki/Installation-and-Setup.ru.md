# Установка и настройка

[English](Installation-and-Setup.md) · [Русский](Installation-and-Setup.ru.md)

## 1. Установите клиент WARP

Плагин — интерфейс к официальному клиенту Cloudflare WARP, поэтому сначала он:

```sh
# Debian / Ubuntu
sudo apt install cloudflare-warp
```

На других платформах следуйте официальному руководству Cloudflare по установке WARP.

Затем один раз зарегистрируйте устройство и примите условия использования:

```sh
warp-cli registration new
warp-cli --accept-tos status
```

## 2. Добавьте плагин в Noctalia

Склонируйте или скачайте этот репозиторий и укажите Noctalia на папку:

```sh
git clone https://github.com/ModernByte/cloudflare-warp.git ~/plugins/cloudflare-warp
noctalia msg plugins source add cloudflare-warp path ~/plugins/cloudflare-warp
noctalia msg plugins enable ModernByte/cloudflare-warp
```

Можно и через **Noctalia → Настройки → Плагины** добавить источник и включить
плагин. Значок WARP появится в панели сразу.

## 3. Три интерфейса

| Где | Что делает |
|---|---|
| Значок в панели | ЛКМ: открыть панель · ПКМ: переключить WARP · наведение: подсказка |
| Плитка Control Center | ЛКМ: переключить · ПКМ: обновить |
| Панель | Кнопка питания, режим, протокол туннеля, DNS-фильтрация, регистрация, обновление, копирование IP |

## 4. Настройка под себя

В настройках доступны: интервал опроса (по умолчанию 3 с), уведомления об изменении
состояния и об ошибках, автоматическая проверка публичного IP и её интервал, текст
значка и компактный режим. Всё работает «из коробки» — меняйте только по вкусу.

## 5. Язык

Интерфейс следует языку Noctalia: английский или русский. Переключите язык оболочки
в настройках Noctalia и перезагрузите плагин.
